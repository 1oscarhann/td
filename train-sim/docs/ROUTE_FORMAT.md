# Route file format (version 2)

Routes live in `public/data/routes/`. A route is either a single JSON file
(`test-track.json`) or a folder with `route.json` plus optional terrain and scenery files
(`west-sussex/`). `npm run validate:routes` checks them with the same code the game uses, so if
it passes, the game loads it.

The West Sussex route is generated by `tools/build-route.mjs`; don't hand-edit it unless you're
happy to lose the edits on the next build. The test track is hand-written and is the easiest
example to read.

## Conventions

- A route is a **network of lines**. Each line has its own alignment and its own **chainage**:
  metres along that line from its start.
- Each line carries one or more **tracks**. A track's key is `line/TRACK`, e.g. `main/UP`.
  `dir: 1` means trains on it run towards increasing chainage, `-1` the other way. UK
  left-hand running puts the `dir: 1` track on the left (negative offset).
- **Points** join a track on one line to a track on another.
- **Speeds** are mph. **Gradients** are per-mille (‰), positive = rising towards increasing
  chainage. 1 in 200 = 5‰.
- **"left"/"right"** (platforms, feathers) is as seen by a driver on that track.
- **Times** are `"HH:MM:SS"`.

## Top level

```jsonc
{
  "id": "west-sussex",            // key for saved scores
  "name": "West Sussex: Chichester – Amberley",
  "description": "…",
  "version": 2,
  "attribution": "…",             // shown nowhere yet, but keep it: ODbL needs credit
  "origin": { "lat": 50.83188, "lon": -0.78185 },   // what x = y = 0 is (generated routes)
  "lines": [ … ],
  "points": [ … ],
  "signalling": { "overlapM": 180 },
  "signals": [ … ],
  "stations": [ … ],
  "platforms": [ … ],
  "levelCrossings": [ … ],
  "leafZones": [ … ],             // optional
  "services": [ … ],              // what the player can drive: at least one
  "traffic": [ … ],               // other trains
  "scenery": { … }
}
```

## Lines

```jsonc
{
  "id": "bognor",
  "name": "Barnham Junction – Bognor Regis",
  "alignment": {
    "points": [[9808.8, -118.4], [9799.4, -122.0], …],  // [x east, y north] metres, any spacing
    "startElevationM": 7
  },
  "lineSpeedMph": 60,             // anywhere not covered by speedLimits
  "ends": { "start": "junction", "end": "buffers" },    // open | buffers | junction
  "tracks": [
    { "id": "UP", "name": "Up Bognor", "offset": -1.7, "dir": -1, "conductorRail": "right" },
    { "id": "DOWN", "name": "Down Bognor", "offset": 1.7, "dir": 1, "conductorRail": "right" }
  ],
  "gradients":   [{ "from": 0, "to": 400, "permille": 2 }],
  "speedLimits": [{ "from": 0, "to": 300, "mph": 20 }],  // lowest wins where they overlap
  "structures":  [{ "type": "bridge", "from": 6886.9, "to": 6894.3 },
                  { "type": "tunnel", "from": 23107.9, "to": 23182.7, "name": "North Stoke Tunnel" }]
}
```

`open` ends let trains run off the edge of the world (they disappear); `buffers` puts a buffer
stop there; `junction` means the line starts or ends at points (nothing is drawn).

## Points

```jsonc
{
  "id": "BJ-D",
  "name": "Barnham Jn (Down main to Bognor)",
  "junction": "Barnham Junction",
  "type": "facing",               // facing: a train on `at` chooses; trailing: `other` merges into `at`
  "at":    { "line": "main",   "track": "DOWN", "position": 10283.1 },
  "other": { "line": "bognor", "track": "DOWN", "position": 0 },
  "crosses": ["main/DOWN"]        // optional: tracks the reverse route crosses on the flat, at `at`'s chainage
}
```

State `N` (normal) keeps a train on `at`; `R` (reverse) sends it to `other`. Trains carry a
`plan` (`{ "BJ-D": "R" }`) and the interlocking sets the points for the nearest train.

Where the reverse route crosses another track on the flat (`crosses`), signals over that diamond
stay red while the points are reversed or moving, the reverse route's own signal stays red while
the crossed track is occupied there, and a train heading for the diamond asks for the points to
be normal.

## Signals

```jsonc
{
  "id": "BN10",
  "line": "main", "track": "DOWN", "position": 10513.1,
  "aspects": "4",                 // "3" or "4" (default 4)
  "kind": "junction",             // starting | protecting | junction | controlled | auto (informational)
  "feather": { "points": "BJ-D", "state": "R", "side": "left" },  // lit when those points are set that way
  "approachControl": true,        // stays red until a train is within 250 m, when the feather route is set
  "aws": true, "tpws": true       // both default to true
}
```

Each signal's section runs to the next signal along whatever route is set, plus the overlap.
AWS magnets, TPWS loops, speed boards, warning boards and whistle boards are worked out from
the route (`src/sim/trackside.js`): they aren't in the file.

## Stations and platforms

```jsonc
{ "id": "CCH", "name": "Chichester", "line": "main", "position": 469.2 }

{
  "id": "CCH-UP", "station": "CCH", "name": "Chichester", "ref": "1",
  "line": "main", "track": "UP", "from": 261.5, "to": 504.9,
  "side": "left",                 // which side the doors open
  "stopMarkers": [{ "cars": 4, "position": 464.9 }, { "cars": 8, "position": 498.9 }]
}
```

## Level crossings

```jsonc
{
  "id": "LC08", "name": "Stockbridge Road", "road": "Stockbridge Road", "roadClass": "primary",
  "line": "main", "position": 524.2,
  "type": "MCB",                  // MCB (full barrier) | AHB | FP (footpath) | BW (bridleway) | UWC (farm)
  "lights": true,
  "whistle": false,               // whistle boards both ways
  "roadPath": [[…], […]]          // optional: the road's centreline for drawing
}
```

Full-barrier crossings hold the signals in rear at red until the barriers are down and the
crossing is proved clear. AHBs start their own warning when a train is about 32 s away.

## Services and traffic

```jsonc
// services: what the player drives
{
  "id": "2H47", "headcode": "2H47", "name": "Amberley → Bognor Regis",
  "description": "…",
  "plan": { "BJ-D": "R" },        // how to set any points on the way
  "calls": [
    { "platform": "AMY-DOWN", "dep": "09:47:00" },
    { "platform": "ARU-DOWN", "arr": "09:52:00", "dep": "09:53:00" },
    …
    { "platform": "BOG-DOWN", "arr": "10:11:30" }
  ]
}

// traffic: other trains
{
  "id": "1W03", "name": "Coastway stopper to Brighton",
  "appear": "00:03:00",           // minutes past every hour; with "once": true, a clock time
  "entry": { "line": "main", "track": "UP", "position": 150 },
  "startsAtPlatform": false,      // true: appears standing in a platform with doors open
  "speedMph": 40,                 // speed when it appears
  "holdS": [55, 100],             // optional: wait this long (random in range) before moving
  "maxSpeedMph": 60,              // optional cap
  "plan": { "FJ-U": "N", "AJ-U": "R" },
  "calls": [{ "platform": "CCH-UP" }, { "platform": "BAA-UP" }, { "platform": "FOD-UP" }],
  "terminates": false             // true: stops for good at the last call
}
```

## Leaf zones and scenery

```jsonc
"leafZones": [{ "line": "main", "from": 19650, "to": 20400 }],   // slippery in autumn

"scenery": {
  "seed": 2026,                   // random trees, fences etc.
  "terrain": "terrain.bin",       // optional heightmap, relative to route.json
  "terrainHeader": { "x0": -3962.6, "y0": -8505.9, "spacing": 75, "nx": 332, "ny": 274,
                     "units": "decimetres, Int16 little-endian, row-major from south-west" },
  "sceneryFile": "scenery.json",  // optional: buildings, roads, water, woods, landmarks
  "hills": "left"                 // flat-world routes only: which side gets distant hills
}
```
